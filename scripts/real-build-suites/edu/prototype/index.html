小树培训学校教务系统 · 原型目录

这些是低保真线框：布局、字段、按钮和交互以原型为准；颜色、字号、间距与组件写法以 DESIGN.md 与 theme.css 为准。 页面里虚线框（.proto-note）是说明；画在页面里的弹窗（.proto-dialog）实际是点按钮后弹出的对话框；页面底部"其他状态"一节（.proto-states）演示加载中、空、出错、无权限，不是页面的一部分。 员工页面的侧栏画的是 admin 能看到的全部入口，实际按角色显示。
