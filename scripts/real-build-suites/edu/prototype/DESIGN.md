## 1. 定位与风格

- 用户是学校的员工（每天长时间使用的后台）和家长（偶尔用手机打开）。员工端讲效率：信息密度高、操作就近；家长端讲简单：一屏一件事、字大一些。
- 风格：干净、克制、可信。白色卡片放在浅灰背景上，绿色是品牌色。
- 反例：营销式大图与横幅、渐变、大圆角卡片、花哨动效、到处都是彩色。

## 2. 布局

- **员工端**：顶部 `.app-header`（左：系统名；右：未读通知 `.badge`、当前用户姓名与角色（点它进修改密码页）、「退出」），下面 `.app-shell` = 左侧 `.sidebar` + 右侧 `.content`（里面套 `.content-inner` 限制最大宽度）。
- **侧栏**按分组显示（`.nav-group`），顺序与入口照 `students.html`：工作台；我的（我的课表、我的课酬，只有 teacher 有）；教务（课表、班级、请假、补课、作业、考试）；招生（线索、试听、学员、订单、优惠）；财务（收款流水、退费、转课、收入确认、课酬标准、工资单）；报表（招生报表、消课与出勤、余额预警）；基础资料（校区、教室、科目、课程、学期与节假日、教师）；系统（用户、公告、操作日志）。**只显示当前角色有权限的入口**（PRD 的权限表），一组里一个入口都没有就不显示这一组；当前页加 `.on`。
- **家长端**：`.parent-header`（孩子姓名切换、通知、退出）+ `.parent-nav`（首页、课表、作业、成绩、通知）+ `.parent-page`（窄的单列）。家长端不出现员工端的任何入口。
- 每个员工页面：`.crumbs`（详情页才有）→ `.page-header`（`h1` 标题 + 右侧主要操作按钮）→ 内容。
- 间距只用 `--space-*`：组件内部 `--space-2`、`--space-3`；组件之间 `--space-4`；区块之间 `--space-6`。
- 窄屏（断点见 theme.css 开头）：员工端侧栏收起，表单与字段列表变单列；表格横向滚动（`.table-wrap`），不让整页横向滚动。

## 3. 排版

- 正文 `--text-base`；辅助信息（时间、编号、提示、字段错误）`--text-sm` 或 `--text-xs`；卡片标题 `--text-lg`；页面标题 `--text-xl`；看板与报表的大数字 `--text-2xl`。
- 金额、数量、课时这类数字用等宽数字（`.num`、`.money`、`.stat .value` 已带上），在表格里右对齐（`.num`）。
- 金额显示为元、保留两位小数，前面不加货币符号以外的单位：`¥1,280.00`（千分位逗号）；负数用 `.negative` 并带负号。
- 时间显示北京时间：日期 `2026-10-15`，时刻 `14:30`，日期时间 `2026-10-15 14:30`；星期写「周一」到「周日」。

## 4. 颜色

- 组件只用语义变量 `--color-*`，不直接用原始色板。
- `--color-primary` 只给一个区域里最主要的那个操作（保存、新建、提交、支付），一个区域最多一个主按钮。
- `--color-danger` 只用于删除、取消、驳回这类不可逆或否定的操作，以及错误信息。
- 状态用标签 `.tag-*` 表示，不用文字颜色表示状态（见第 6 节）。

## 5. 组件

| 组件 | 类名 | 用法 |
|---|---|---|
| 卡片 | `.card`，`.card-header`（标题与右侧按钮）、`.card-body` | 表格、表单、详情的容器；详情页按主题分几张卡片 |
| 按钮 | `.btn`；`.btn-primary` 主要操作；`.btn-danger` 危险操作；`.btn-link` 文字按钮（`.danger` 红色）；`.btn-sm` 表格行内 | 提交中加 `disabled`，文字改成「保存中…」；危险操作点了先弹确认框 |
| 表格 | `.table-wrap` > `.table`；数字列 `.num`；操作列 `.ops`；停用或已取消的行 `tr.muted` | 列表都用表格；操作列在最右，用 `.btn-link` |
| 筛选条 | `.toolbar`；搜索框 `.input.search`；`.grow` 把右侧按钮推到最右 | 列表上方：搜索、筛选下拉、右侧的导出与新建 |
| 分页条 | `.pager`，左边 `.total` 显示「共 N 条」 | 分页的列表都有；页码与筛选写进网址参数 |
| 表单 | `.form-grid`（两列）、`.field`、`.field-label`（必填加 `.required` 星号）、`.input` / `.select` / `.textarea`、`.field-hint`、`.field-error`、`.form-actions` | 校验不通过给控件加 `.invalid`，错误写在下方的 `.field-error`（没有错误也占位，页面不跳动） |
| 对话框 | `.dialog-backdrop` > `.dialog`（`.wide` 加宽），`.dialog-header`、`.dialog-body`、`.dialog-footer` | 新建与编辑基础资料、确认操作、填写原因（停课、驳回、流失）；Esc 关闭，焦点放在第一个输入框 |
| 页签 | `.tabs`，当前项 `.on` | 详情页内切换（学员详情的资料、课时、订单、考勤、余额）；当前页签写进网址参数 |
| 字段列表 | `.desc`（三列）> `.item` > `dt` + `dd` | 详情页的基本信息 |
| 数字卡片 | `.stats` > `.stat`（`.label`、`.value`、`.sub`），需要注意的加 `.warn` | 看板、报表与汇总的指标 |
| 标签 | `.tag` 与 `.tag-success` / `.tag-info` / `.tag-warning` / `.tag-danger` | 状态、类型（见第 6 节的对照） |
| 角标 | `.badge` | 未读通知数 |
| 提示条 | `.alert-error` / `.alert-info` / `.alert-warning` | 表单整体的错误放在表单顶部；页面级的说明与警告 |
| 轻提示 | `.toast`（失败加 `.error`） | 操作成功或失败后不离开页面时，显示 2.5 秒 |
| 周课表 | `.week`：`.head`（今天加 `.today`）、`.hour`、`.cell`，课次 `.lesson-chip`（`.completed`、`.cancelled`） | 课表、教师课表（家长端课表不用它，按天列出 `.list-item`） |
| 并排两列 | `.grid-2`（窄屏变一列） | 两张并列的卡片（如收入确认的按课程、按校区） |
| 单选组 | `.radio-group` > `.checkbox`（里面是 `type=radio`） | 点名的四种状态、少量互斥选项 |
| 时间线 | `.timeline` | 跟进记录、课时流水、操作记录 |
| 列表行 | `.list-item` | 家长端的列表（孩子、课程、作业、通知） |
| 孩子切换 | `.child-switch` > `.btn`，当前孩子加 `.on` | 家长绑定了多个孩子时，家长端页面顶部切换（写进网址参数 `student_id`） |

## 6. 状态的标签

| 取值 | 标签 |
|---|---|
| 启用、在读、已支付、已批准、已完成、出勤、已转化、已提交 | `.tag-success` |
| 待处理、待支付、待审批、筹备、草稿、请假、已约试听 | `.tag-warning` |
| 进行中、开课、已确认、已联系、已试听、迟到 | `.tag-info` |
| 已取消、已驳回、流失、缺勤、停用、停读 | `.tag-danger`（停用、停读这类"不再使用"的同时整行加 `.muted`） |
| 已结课、已发放、其他中性的 | `.tag` |

状态文字一律用中文（PRD 里各字段的中文说明），不显示英文取值。

## 7. 四种状态

每个取数据的区域都有这四种状态，和有数据时显示在同一个位置：

| 状态 | 写法 |
|---|---|
| 加载中 | 卡片里三到五行 `.skeleton-row` |
| 空 | `.state`：一句说明（`.title`），下面说下一步怎么做，有权限时加一个主按钮（如「新建班级」）；筛选后没有结果时说「没有符合条件的…」并给「清除筛选」 |
| 出错 | `.state`：说明原因（接口的 `message`），加「重试」 |
| 无权限（403） | `.state`：「没有权限查看」，加「返回工作台」；不跳转（只有未登录 401 才跳到 `/login`，登录后回到原页面） |

## 8. 交互与可访问性

- 可点的元素都有 hover 样式；键盘聚焦时显示 `--color-focus` 的轮廓，不能去掉。
- 动效只用 `--duration-fast`，只过渡颜色，不做位移和缩放。
- 只用键盘能完成所有操作：回车提交表单，Esc 关闭对话框，Tab 顺序和视觉顺序一致。
- 表单提交失败：接口返回的 `message` 显示在对应字段下（能判断是哪个字段时）或表单顶部的 `.alert-error`；不清空用户已经填的内容。
- 金额输入框按元输入（两位小数），提交时换算成分；显示时从分换算成元。

## 9. Do / Don't

- Do：颜色、字号、间距、圆角、阴影都用 theme.css 的变量；缺的值先在 theme.css 里加语义变量再用。
- Do：先复用已有组件；新组件写进上面的组件表。
- Do：列表页、详情页、表单的结构跟原型保持一致（同样的字段、按钮和位置）。
- Don't：不写死颜色值和间距（`100%`、`1px` 边框这类布局值除外）。
- Don't：不用渐变、彩色阴影、大圆角，不用 emoji 当图标；需要图标时先用文字。
- Don't：不加原型里没有的装饰（插画、欢迎横幅、动画）。
- Don't：不在页面上显示英文的状态取值、接口字段名或原始的分。

## 10. 完成后自查

- 除 theme.css 外，样式里没有 `#` 开头的颜色值。
- 每个列表页的四种状态都能看到；表单的字段错误显示在字段下方。
- 侧栏只显示当前角色有权限的入口；家长端看不到员工端的入口。
- 只用键盘能走完登录、新建学员、报名下单、点名。
