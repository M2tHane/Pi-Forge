页签「班级出勤」（?tab=attendance）

导出 CSV
班级必选，写进网址参数 ?tab=attendance&class_id=12；没选班级时不发请求，表格位置显示「选择一个班级查看每个学员的出勤」（见下方其他状态）。班级下拉来自 GET /api/classes?page_size=100（超过再逐页取完；全部状态，开课的在前，名称后带班级编号），可以输入名称或编号过滤。 「导出 CSV」：没选班级时禁用；点了下载 GET /api/exports/attendance.csv?class_id=12，文件名 attendance-20261015.csv，内容同下表（列：学号、姓名、出勤、迟到、缺勤、请假、出勤率）。下载失败时轻提示接口的 message。 只有 admin 与 academic 能看到这个页签和导出按钮；finance 只有「消课统计」，页签条也不显示。
