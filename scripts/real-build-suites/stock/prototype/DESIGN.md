## 1. 定位与风格

- 两三个仓库的小商贸公司内部用的后台，仓管员每天长时间使用：信息密度高、操作就近、看一眼就知道单据处在什么状态。
- 风格：朴素的管理后台。深色顶栏、浅灰左侧导航、白色主体；列表都是带边框的表格。
- 反例：营销页式的大图与横幅、渐变、大圆角卡片、阴影堆叠、花哨动效。

## 2. 布局

- 登录后的每个页面：顶栏 `.top`，下面外框 `.frame` = 左侧导航 `.side` + 主体 `main`。登录页没有顶栏和导航，用 `.center` 把 `.dialog.login` 放在页面中间。
- 顶栏：左边产品名「小仓库进销存」，`.grow` 撑开，右边「用户名（角色）」与「退出」。
- 导航：项目与顺序照原型（看板、商品、分类、往来单位、仓库、库存、采购单、销售单、调拨、报表、用户）；当前页加 `.on`；「用户」只有 admin 看得到（原型里写成「用户（admin）」只是说明）。详情页（采购单详情、销售单详情）高亮所属列表的那一项。
- 主体：`h1` 页面标题 → 工具条 `.bar`（筛选、搜索在左，`.grow` 把导出与新建推到最右）→ 表格或表单。
- 字段多的表单用两列 `.form2`；两块内容左右并排用 `.cols`（分类树与右侧编辑面板）。
- 间距只用 `--space-*`：组件内部 `--space-2xs`～`--space-sm`，组件之间 `--space-sm`～`--space-md`，区块之间 `--space-lg`～`--space-xl`。

## 3. 排版

- 正文 `--text-base`；辅助说明（`.note`）、字段错误（`.err`）`--text-sm`；看板欢迎语 `--text-lg`；数字卡片的大号数字 `--text-xl`。`h1`、`h2` 用浏览器默认字号。
- 只用 `--font-sans`，粗体用 `--weight-bold`。
- 金额：接口里是分，页面显示为元、两位小数、千分位逗号。表格里不加货币符号（`1,850.00`），数字卡片前面加 `¥ `（`¥ 31,560.00`）。数量是整数，也加千分位。
- 数字列（金额、数量、库存）加 `.num`：右对齐、等宽数字。
- 时间：列表与详情都显示本地时间 `MM-DD HH:mm`；日期输入用 `<input type="date">`。

## 4. 颜色

- 组件只用 theme.css 里的 `--color-*` 变量，不写死颜色值。
- `--color-primary` 只给一个区域里最主要的那个操作（新建、保存、确认、提交盘点），一个区域最多一个主按钮。
- `--color-danger` 只用于删除、取消单据这类不可逆的操作，以及错误信息。
- 状态用标签 `.tag` 表示（见第 5 节），不用文字颜色表示状态。

## 5. 组件

| 组件 | 类名 | 用法 |
|---|---|---|
| 按钮 | `button` | 普通操作；提交中加 `disabled`，文字改成「保存中…」「登录中…」「导出中…」，防止重复提交 |
| 主按钮 | `button.primary` | 新建、保存、确认、登录、查询 |
| 危险按钮 | `button.danger-btn` | 确认框里的「删除」「取消单据」；列表行里文字链接式的危险操作用 `a.danger` |
| 工具条 | `.bar` | 表格上方一行；也用于表单底部的按钮行（`.grow` 把按钮推到右边） |
| 表格 | `table` | 列表都用表格；数字列 `.num`；停用或已取消的行 `tr.off`（变灰）；低于安全库存的行 `tr.low`（橙底）；操作列在最右，用文字链接 |
| 对话框 | `.dialog` | 新建与编辑基础资料的表单、右侧编辑面板、单据详情的表单 |
| 确认框 | `.dialog.modal` | 删除、停用以外的单据操作（确认、入库、出库、执行、取消）、提交盘点前确认；写明对象与后果，按钮「取消」与操作名 |
| 字段错误 | `.err` | 输入框下方的红字，内容是接口返回的 `message`；页面自己先拦的错误（必填、金额格式、日期先后）也写在这里 |
| 失败提示 | `.alert` | 页面顶部红色条，显示接口的 `message`，右边的 `button.close`（×）关闭，不自动消失；能重试的加「重试」按钮 |
| 普通提示 | `.alert.info` | 蓝色说明条，如登录页的「登录已失效，请重新登录」 |
| 成功提示 | `.toast`，放在 `.toasts` 里 | 右上角绿色提示，3 秒后自动消失；原型里为了展示画在页面中间 |
| 标签 | `.tag` | `.tag.ok` 绿：启用、已入库、已出库、已完成；`.tag.info` 蓝：已确认；默认灰：草稿、停用、已取消 |
| 数字卡片 | `.cards` > `.card`，数字放 `strong`，说明放 `small` | 看板与报表的指标；需要注意的（低于安全库存）加 `.warn` |
| 页签 | `.tabs` | 同一页内切换视图（库存页的库存查询、库存流水、盘点）或筛选（往来单位的类型），当前项加 `.on`；同一时间只显示当前页签的内容 |
| 树 | `.tree` | 分类的层级列表，下级缩进 |
| 说明 | `.note` | 灰色小字，补充说明 |
| 页面不存在 | `.empty-page` | 「页面不存在」与回到看板的链接 |

## 6. 状态

每个取数据的区域（表格、卡片组、树、详情）都有下面这些状态，显示在有数据时的同一个位置：

| 状态 | 写法 |
|---|---|
| 加载中 | 表格里一行 `td.msg`「加载中…」；不是表格的区域用 `p.msg`；数字卡片的数字显示「…」 |
| 空 | 表格里一行 `td.msg`，说明下一步怎么做（「还没有商品。点"新建"添加。」）；筛选后没有结果写「没有符合条件的…」加「清除筛选」 |
| 出错 | `.alert` 显示接口的 `message` 加「重试」；表格、卡片不显示旧数据或假数据 |
| 无权限（403） | `.alert` 提示，不跳转；按钮已按角色隐藏，正常不会出现 |
| 只读用户（viewer） | 不显示新建、编辑、停用、删除与单据操作按钮；查询、筛选、导出照常 |

- 没登录或任何请求返回 401：清掉本地令牌，跳到登录页，登录页顶部 `.alert.info` 提示「登录已失效，请重新登录」；登录后回到原来要打开的页面。见 common-states.html。
- 表单提交失败：对话框不关，已填的内容保留，错误写在对应字段下方的 `.err`；不是某个字段的错误（409 状态不允许、库存不足）用 `.alert`。
- 用 `hidden` 属性切换状态（theme.css 已让 `[hidden]` 盖过组件自己的 `display`）。

## 7. 交互

- 删除与单据操作先弹 `.dialog.modal` 确认；停用、启用不弹确认，直接切换并给 `.toast`。
- 操作成功：对话框关闭，列表或单据刷新为最新状态，给 `.toast`。
- 列表页的筛选在前端改变后立即重新请求；搜索框去掉首尾空白后为空时不带 `q`。
- 导出：用带登录令牌的请求取回文件再保存（普通链接带不上令牌），文件名用接口给的（`products.csv`、`stock.csv`）；导出中按钮禁用并显示「导出中…」。

## 8. Do / Don't

- Do：颜色、字号、间距、圆角、阴影都用 theme.css 的变量；缺的值先在 theme.css 加语义变量再用。
- Do：先复用上面的组件；需要新组件时加进产品里的 theme.css 与组件表。
- Don't：不写死颜色值和间距（`100%`、`1px` 边框这类布局值除外）。
- Don't：不用渐变、彩色阴影、大圆角；不用 emoji 当图标。
- Don't：不加原型里没有的装饰（插画、欢迎横幅、动画），不加原型里没有的页面元素。
- Don't：页面里不写内联 `style`。

## 9. 完成后自查

- 除 theme.css 外，样式里没有 `#` 开头的颜色值。
- 每个列表页都能看到加载中、空、出错三种状态；viewer 登录后看不到任何写操作按钮。
- 金额都显示为元、两位小数；提交时换算成分。
- 用 `hidden` 藏起来的元素真的看不见（登录页没有空顶栏）。
