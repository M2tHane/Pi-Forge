# 小组待办 设计说明

## 1. 定位与风格

- 3～20 人小团队的待办清单，打开就能用，不需要说明。
- 风格：简洁、克制、信息清楚；白色卡片放在浅灰背景上。
- 反例：营销页式的大图与横幅、渐变、大圆角卡片、花哨动效。

## 2. 布局

- 内容区用 `.page`（宽屏居中）；只有一个表单的页面（登录）再加 `.page-narrow`。
- 间距只用 `--space-*`：组件内部 `--space-2`，组件之间 `--space-3` 或 `--space-4`，区块之间 `--space-6`。
- 窄屏（断点见 theme.css 开头）：工具条与列表行换行，不出现横向滚动。

## 3. 排版

- 正文 `--text-base`；辅助信息（时间、负责人、字段错误、说明）`--text-sm`；顶栏标题 `--text-lg`；登录页标题 `--text-xl`。
- 时间与数字用等宽数字（`.meta` 已带上）。
- 只用 `--font-sans`。

## 4. 颜色

- 组件只用语义变量 `--color-*`，不直接用原始色板（`--gray-*`、`--blue-*`、`--red-*`）。
- `--color-primary` 只给一个区域里最主要的那个操作，一个区域最多一个主按钮。
- `--color-danger` 只用于删除等危险操作和错误信息。

## 5. 组件

| 组件 | 类名 | 用法 |
|---|---|---|
| 顶栏 | `.app-header` | 登录后的每个页面都有：左边产品名，右边当前用户与「退出」 |
| 卡片 | `.card`，内边距 `.card-body` | 表单、列表、状态提示的容器 |
| 按钮 | `.btn`；主按钮再加 `.btn-primary` | 主按钮给最主要的操作（登录、添加）；提交中加 `disabled`，文字改成「登录中…」 |
| 整行按钮 | `.btn-block` | 只有一个表单的页面里的提交按钮 |
| 危险操作 | `.btn-link-danger` | 列表行里的「删除」；点了先用浏览器确认框确认 |
| 输入框 | `.input`，标签 `.field-label` | 校验不通过加 `.invalid`，错误写在下方的 `.field-error`（没有错误也占位，页面不跳动） |
| 表单错误 | `.alert-error` | 整个表单的错误（如「邮箱或密码错误」），放在表单顶部 |
| 工具条 | `.toolbar` | 一行里的输入框与按钮；占满剩余宽度的输入框加 `.grow` |
| 分段筛选 | `.segmented` | 互斥的筛选按钮，选中的加 `.on`；选中的值写进网址参数 |
| 列表 | `.card .list`，每行 `.list-row` | 主要文字加 `.grow`；已完成的行加 `.done`；辅助信息用 `.meta` |
| 分页 | `.pager` | 上一页、第 x / y 页、下一页；到头时对应按钮禁用 |
| 提示条 | `.toast` | 操作失败但不离开页面时（例如删除被拒 403），显示 2.5 秒 |

## 6. 四种状态

每个取数据的区域都有这四种状态，和有数据时显示在同一个位置：

| 状态 | 写法 |
|---|---|
| 加载中 | `.card .list .skeleton`：三行灰色占位条 |
| 空 | `.card .state`：一句说明，加一个下一步的主按钮（如「新建任务」） |
| 出错 | `.card .state`：说明原因，加「重试」 |
| 无权限 | `.card .state`：说明没有权限，加「返回」；不跳转（只有未登录才跳到登录页） |

## 7. 交互与可访问性

- 可点的元素都有 hover 样式；键盘聚焦时显示 `--color-focus` 的轮廓，不能去掉。
- 动效只用 `--duration-fast`，只过渡颜色，不做位移和缩放。
- 只用键盘能完成所有操作：回车提交表单，Tab 顺序和视觉顺序一致。

## 8. Do / Don't

- Do：颜色、字号、间距、圆角、阴影都用 theme.css 的变量；缺的值先在 theme.css 加语义变量再用。
- Do：先复用已有组件；新组件写进上面的组件表。
- Don't：不写死颜色值和间距（`100%`、`1px` 边框这类布局值除外）。
- Don't：不用渐变、彩色阴影、大圆角。
- Don't：不用 emoji 当图标；需要图标时先用文字按钮。
- Don't：不加原型里没有的装饰（插画、欢迎横幅、动画）。

## 9. 完成后自查

- 除 theme.css 外，样式里没有 `#` 开头的颜色值。
- 四种状态在页面上都能看到。
- 只用键盘能走完登录和新建任务。
