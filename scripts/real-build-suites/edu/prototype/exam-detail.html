页面先查：分数是 0 到满分的数、最多一位小数，错误写在这一格下面，有错时不提交。
「保存成绩」调用 PUT /api/exams/:id/scores，请求体 {"scores": [{"student_id", "score"}]}：填了分数的传分数，勾缺考的传 null，都没有的不放进请求。接口返回 400（例如学员不是考试当天在班的）时不切换，把 message 显示在卡片顶部 alert-error。成功后切回「成绩与排名」（用接口返回的列表），重新取统计，提示「成绩已保存」。录入时离开页面要确认「成绩还没保存，确定离开吗？」。
